# SmartQ Design System & Color Palette

The SmartQ visual style is designed to inspire trust, clarity, and efficiency across healthcare, banking, and public service environments.

## Color Tokens

### Primary Brand Palette

| Token Name | Hex Code | Usage |
|---|---|---|
| `Primary Deep Blue` | `#123B66` | Primary buttons, active headers, navigation bars, key emphasis |
| `Secondary Teal` | `#159A9C` | Progress indicators, live queue status highlights, action badges |
| `Light Accent Blue` | `#E8F4FA` | Card backgrounds, highlighted infoboxes, selected state fills |
| `Dark Navy Text` | `#0F2742` | Primary typography, section headings, prominent labels |
| `Slate Subtext` | `#5B6B7F` | Secondary typography, metadata, timestamps, helper text |
| `Soft Background` | `#F8FAFC` | App screen backgrounds, table alt-rows |

### Status Colors

| State | Hex Code | Meaning |
|---|---|---|
| `Success` | `#22A06B` | Arrived, Served, Verified, Counter Active |
| `Warning` | `#E8A317` | Arrival Window Active, Approaching Turn, Grace Period Warning |
| `Error / Expiry` | `#D64545` | Expired Token, Cancelled Token, Counter Inactive, System Error |
| `Info` | `#2B88D8` | AI Prediction updates, System notifications |

---

## 60-25-10 Design Balance Rule

- **60% Dominant Base**: Soft White / Neutral background (`#F8FAFC`, `#FFFFFF`)
- **25% Structural Brand Color**: Deep Blue (`#123B66`) for containers, cards, headers
- **10% Accent**: Teal (`#159A9C`) for interactive elements, buttons, and progress rings
- **5% Functional Feedback**: Status colors for real-time queue states
